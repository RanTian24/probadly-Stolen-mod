# 模组规划器 · Module Planner v0.2.0

深空当铺（Probably Stolen）游戏内 Mod：**图标图鉴 + 筛选 + 最优组合计算 + 仓库总览 + 排版双方案可视化**。

基于 **PSApi**（官方级内容包框架）开发，无需写 C#，纯 JSON / PSScript / PSUI。

---

## 功能

1. **图标图鉴**（F5 面板顶部）：17 种模组的游戏原版贴图（wiki 提取，16 张 + 化学模块待补）。
2. **筛选**：类别（全部/通用/节点/专用）× 优化目标（均衡/纯性能/纯效率/纯质量/节点增效）× 只看已持有。
3. **最优组合计算**：输入舱位 W×H → 贪心装箱 → ASCII 排版网格（`.`空 `#`模组 `+`节点）。
4. **仓库总览**（实时）：
   - 背包 + 后仓（含容器嵌套）所有模组：数量、实时效果值（TEMP 当前生效值优先）、损坏/报废/已损耗标记
   - 店内机器盘点：`machine.find` 搜全店 15 处库存（后仓/柜台/展示区/隐藏区/已售区/垃圾箱/博士柜/地摊/夜市/雇员包等）
   - 走私者暗格：PSApi 框架暂无读取 API，面板如实标注
5. **排版可视化双方案**：
   - **方案 A · 排版预览台（游戏原生 UI）**：后仓自动发放的机器物品，双击打开 → 游戏原生舱位格子（grid_slot）→ 点「生成排版预览」把最优组合的真实模组自动放入（游戏内真实贴图 + 真实占格形状，锁定防拿走，清空即销毁预览件）。舱外区域用 shape 洞裁剪，视觉上就是 W×H 舱位。
   - **方案 B · 图标图鉴**：F5 面板顶部静态图标区（pack: 图源）。
6. **联动**：规划器点「计算最优组合」→ 结果写入包级 state（mp_w/mp_h/mp_last_placed）→ 预览台读取渲染。

## 安装

1. `PSApi_2.0.1.dll` → `<游戏目录>/Mods/`
2. `module_planner` 整个文件夹 → `<游戏目录>/UserData/PSApi/packs/`
3. 启动游戏，读档后后仓自动获得「排版预览台」×1（没有时才补发，不重复）

## 使用

- **F5**：规划器面板（图鉴/筛选/计算/仓库总览）
- **后仓双击「排版预览台」**：点「生成排版预览」看游戏原生贴图排版

## 已知边界

- 原版机器舱位内已装的模组：PSApi 无读取 API（仅自定义机器可读槽位）
- 走私者暗格内容：PSApi 无读取 API
- 化学设备模块图标：wiki 未收录，图鉴显示文字兜底
- 模组占格形状（sw×sh）为图标尺寸推断，游戏内实际 footprint 若不同，以实测为准

## 数据来源

深空当铺 Wiki（gamewikistation.com，2026-09-26 版）模组数值；效果类为「说明值」，以游戏内实际为准。
